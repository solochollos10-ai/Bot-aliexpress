# Bot AliExpress — proyecto AciertaChollo

Repositorio de desarrollo relacionado con la extracción, preparación y comunicación de ofertas de **AliExpress** para el ecosistema AciertaChollo.

## Para qué sirve el proyecto

El trabajo sobre bots de ofertas persigue simplificar la consulta y distribución de información de productos, enlaces y cupones. Los precios y descuentos mostrados por cualquier canal deben contrastarse con los del vendedor en el momento de realizar la compra.

## Nota de uso

Este repositorio es un recurso técnico; no constituye un catálogo de descuentos con vigencia garantizada. Revisa el código, sus dependencias y la configuración antes de utilizarlo.

**Afiliación:** AciertaChollo es un proyecto propio que puede obtener comisiones de algunos enlaces comerciales. Unirte a su canal de Telegram es gratuito.
